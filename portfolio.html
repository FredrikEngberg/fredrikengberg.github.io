Om mig

Jag studerar mjukvaruutveckling med inriktning mot inbyggda system och IoT.

Mitt fokus ligger på att förstå hela kedjan från kod och mikrokontroller till sensorer, kommunikation, automation och systemintegration.

Jag dokumenterar mina projekt på GitHub både för att följa min egen utveckling och för att visa hur jag arbetar med problemlösning och tekniska lösningar.
